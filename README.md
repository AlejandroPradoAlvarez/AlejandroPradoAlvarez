## Proyectos destacados

### Spring Boot Inventory API
API REST de inventario y gestión de productos desarrollada con Spring Boot. Incluye productos y categorías, control de stock, SKU único, filtros, búsqueda, paginación, validación, manejo global de excepciones, documentación con Swagger/OpenAPI, tests automatizados y configuración con Docker Compose.

### Laravel Ecommerce Platform
Plataforma ecommerce desarrollada con Laravel que incluye catálogo de productos, carrito, pedidos, roles de usuario, autorización y panel de administración.

### PHP MVC Appointment System
Sistema de gestión de citas desarrollado con PHP sin frameworks, utilizando una arquitectura MVC propia, Router, Active Record, autenticación y medidas de seguridad como CSRF y consultas preparadas.

### Laravel Shopping Cart
Aplicación de carrito de compra desarrollada con Laravel, centrada en gestión de sesiones, control de stock y procesamiento de pedidos mediante transacciones.
